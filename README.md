# Ghost Codex Inspect

## 远程访问

在“中转台”开启“允许远程访问”后，服务监听 `0.0.0.0`，覆盖所有 IPv4 网卡。关闭时只监听 `127.0.0.1`。

首次使用时，先在“远程访问入口”设置访问密钥。密钥只提供设置和重新设置，遗失后请直接重设。已有密钥继续有效。

启动中转后，入口会列出各网卡的 IPv4 地址，以及 `127.0.0.1` 和 `localhost`。关闭远程访问时只列出本机入口。地址可直接选中文字复制，页面不提供 URL、token 或密钥复制按钮。浏览器打开带 token 的链接，输入密钥后进入远程界面；连接仍须通过 token 校验。

token 默认每次启动中转重新生成。勾选“固定 token（手动轮转）”后，当前 token 会保存并跨重启保留。点击“立即轮转 token”会使旧 token 和登录状态失效，并断开全部远程端。远程端须使用新链接重新验证密钥。

手机端可直接触摸远程画面。输入文字时，先点画面中的输入框；如键盘未弹出，点顶栏的“打开键盘”。DOM 重绘和视频流模式共用触摸与键盘转发，支持中文输入、退格和回车。

自适应模式支持 10% 至 200% 缩放，每次增减 5%，并记住上次使用的比例。

监听地址 `0.0.0.0` 表示所有接口，浏览器应使用宿主实际 IP 或域名访问。本工具提供 HTTP，跨网络使用时建议配置 HTTPS 代理或加密隧道。
