# 中转安全模型：默认绑 127.0.0.1，局域网显式开关，token 每次启动随机生成

CDP 端口等于目标应用的任意代码执行权，token 泄漏约等于整机沦陷。决定：中转 WS/HTTP 服务默认只绑 127.0.0.1；「允许局域网访问」开关显式开启后绑首个非回环 IPv4（**绝不绑 0.0.0.0**）；token 每次启动中转随机生成，停止即失效；访问 URL 以 `#t=<token>` fragment 携带（不进 HTTP 请求行/日志）；鉴权失败以 4401 关闭。公网访问不走中转自身，留给隧道层（SSH/tailscale/frp+TLS），属范围外。

## Consequences

- 跨机使用必须先开隧道，中转自身永远不暴露公网。
- token 出现在远程端浏览器地址栏历史里属可接受代价（fragment 不上行）；分发 URL 时注意接收方可信度。
