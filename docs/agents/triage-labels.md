# 分类标签

这些 skills 使用五种规范分类角色。本文件把角色映射到当前仓库 issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 当前跟踪器中的标签 | 含义                                     |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue                    |
| `needs-info`               | `needs-info`         | 等待报告者补充信息                        |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给离线代理处理              |
| `ready-for-human`          | `ready-for-human`    | 需要人类实施                              |
| `wontfix`                  | `wontfix`            | 不会处理                                  |

skill 提到某个角色时（例如“应用可交给离线代理的分类标签”），使用表中对应的标签字符串。

编辑右侧列，使其符合实际使用的标签词汇。
